Keyboard shortcuts

Ctrl+Q explores precedents. Ctrl+Shift+Q explores dependents. Ctrl+Shift+M toggles the active sheet’s map. Up and Down visit reference cells. Right follows the selected reference and Left returns to that step. Home selects the current trace root. With formula components shown, Right and Left expand or collapse the expression tree. Esc returns to the root and closes. Enter closes at the previewed cell. Ctrl+Backspace returns inside the pane. From the worksheet use Ctrl+Alt+B to return.
